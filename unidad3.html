¿De qué parte tomas una tortilla del montón?

Imaginen que estamos comiendo con tortillas, ¿de qué parte toman la tortilla, la que está hasta abajo, la que está en medio o la primera? Pues de la primera; si intentas sacar a la fuerza una tortilla que está hasta abajo, ¿qué va a pasar?

Así es como funciona una pila, último en entrar primero en salir, es lo que se conoce como el principio LIFO (Last In, First Out), que en español significa: Último en Entrar, Primero en Salir. El último dato que guardas es obligatoriamente el primero que tienes que sacar.

La última en entrar es la primera en salir (LIFO)

3.1 Apuntadores
¿Para qué sirve un apuntador?

Un apuntador o puntero contiene la dirección de memoria de una variable que tiene un valor específico. Los apuntadores son muy importantes porque permiten enlazarse con otros nodos.

La forma de declarar un apuntador es de la siguiente forma:

char *Letra;
  • char es el tipo de dato.
  • *Letra es una variable que se declara apuntador; es importante considerar que para declarar el apuntador siempre debe de ir el asterisco (*) antes del nombre de la variable.
3.2 Pilas
¿Qué es una pila?

Las pilas son una estructura de datos dinámica lineal. Son una colección de elementos organizados de forma LIFO (Last In, First Out), que significa el último elemento en entrar es el primero en salir. Relacionado con la vida real, existen varios ejemplos de pilas: de libros, de platos, de tortillas, etc.

edit_noteEjercicio Reflexivo

Para comprender más el comportamiento de la estructura de datos dinámica Pila, analiza mentalmente su funcionamiento con elementos apilados:

  1. Utilizando el funcionamiento de una pila, ¿cómo sería la entrada de los elementos?
  2. Utilizando el funcionamiento de una pila, ¿cómo sería la salida de los elementos?
3.2.1 Representación

Para representar a una pila en memoria, se utilizarán arreglos unidimensionales (vectores) donde se almacenarán los elementos, por ejemplo: Vector_Pila[6].

Se utiliza una variable de control fundamental: Tope, que contiene la dirección de memoria actual (o índice) del último elemento apilado.

  • Push: Insertar un elemento al Vector_Pila[Tope].
  • Pop: Eliminar un elemento del Vector_Pila[Tope].

Los elementos se pueden insertar (añadir) o eliminar (suprimir) desde un extremo de la pila llamado "Tope". Si la pila está vacía, eso quiere decir que no tiene elementos, por lo que la variable Tope tendría asignado el valor de -1 (o sea Tope = -1).

  • Cada vez que se inserta un elemento (Push), este se coloca en la posición de la variable Tope. Posteriormente Tope se incrementa en uno.
  • Cada vez que se elimina un elemento (Pop), Tope se decrementa en uno.
Tope = -1

Vector_Pila[6] vacío

3.2.2 Formas de uso

La estructura de datos dinámica Pila se puede usar de diferentes formas. Por ejemplo, utilizando un Vector_Pila[5] de tamaño 5 de tipo de dato char, donde se desean agregar las siguientes letras: A, B y C, en ese orden. Se tendría que llamar la función Push tres veces, la letra 'C' estará en la cima de la pila, donde la variable Tope tendría asignado el valor de 3 y el Vector_Pila[Tope] tendría asignado 'C'.

Si se desea eliminar un elemento del Vector_Pila[Tope], se manda a llamar la función Pop y el primer elemento en eliminarse es 'C', porque fue el último en entrar. El resultado de esta acción es que el Tope se decrementa. Siguiendo esta dinámica, se podrán insertar y eliminar los elementos de manera continua.

Tope = 3 ('C' en la cima)
A
B
C

Push(A) → Push(B) → Push(C)

3.2.3 Implementación

Existen formas de poner en práctica las pilas, destacando:

  1. Llamado de funciones, subrutinas, procedimientos, programas, etc.
  2. Expresiones aritméticas.
1. Llamado de funciones

Las funciones son un conjunto de procedimientos encapsulados en un bloque. El llamado de funciones nos permite desarrollar programas eficientes que permiten modularizar nuestro código. Al momento de declarar la función, es necesario asignarle el tipo de dato, el nombre y los valores que espera recibir.

Algoritmo de Inserción (Función Push)

Este algoritmo describe el proceso para añadir un Dato a una estructura de tipo pila implementada mediante un arreglo. Se asume que Tope inicia en 0 (pila vacía) y que Max es la capacidad máxima.

Push_Pila(Tope, Dato) // Inserta el elemento DATO a la pila SI Tope < Max ENTONCES // Verifica si existe espacio disponible Vector_Pila[Tope] = Dato // Almacena el dato en la posición actual Tope = Tope + 1 // Incrementa a Tope a la siguiente posición SINO DESPLEGAR MENSAJE: "La Pila está llena" FIN SI

Algoritmo de Eliminación (Función Pop)

Para que la eliminación sea válida, es imperativo comprobar previamente que la estructura no se encuentre vacía.

Pop_Pila(Tope) // Elimina el elemento en la posición de Tope SI Tope > 0 // Verifica que la pila contenga elementos Tope = Tope - 1 // Decrementa Tope a la posición anterior Vector_Pila[Tope] = NULO // Elimina/limpia el dato SINO DESPLEGAR MENSAJE: "La Pila está vacía" FIN SI

2. Expresiones aritméticas

Las expresiones aritméticas son una combinación de variables y operadores de distintos niveles de precedencia (paréntesis, potencia, multiplicación/división, suma/resta).

Están representadas de tres formas:

  • Notación Infija: los operadores en medio (ej. A + B).
  • Notación Prefija: el operador antes (ej. + AB).
  • Notación Postfija: el operador al final (ej. AB+).

Pasos para convertir una expresión infija a postfija:

  1. Los operadores de prioridad más alta se convierten primero.
  2. Después de que una parte ha sido convertida, se trata como un solo operando.
  3. Si son de igual prioridad, se procesan de izquierda a derecha.

Pasos para evaluar expresiones postfijas:

  1. Explorar la expresión de izquierda a derecha.
  2. Cada vez que se encuentra un operador, aplíquese a los operandos inmediatamente precedentes.
  3. Continuar la exploración a la derecha.

3.2.4 Operaciones permitidas

Las operaciones fundamentales son Push(TOPE, DATO) y Pop(TOPE). Se gestionan mediante el índice de control Tope.

edit_noteCierre: Consolidación y conclusión (Pilas)

En el uso de software diario, ¿cuándo se utiliza una estructura Pila? Al utilizar un navegador, cada página que visitas se hace Push a una pila. Al dar clic en el botón de la flecha de regresar, se hace Pop. Las Pilas son muy útiles en programación cuando una función se llama a sí misma (recursión). Permiten realizar operaciones rápidas y controlar el orden inverso de las tareas.

3.3 Colas
¿Qué es una cola?

Figúrense que van al banco a pagar algunos servicios. Hay una fila de personas esperando frente a los cajeros. Llega un cliente nuevo, ¿dónde se coloca? ¿A quién atiende el empleado?

Así es como funciona una cola, primero en entrar primero en salir, es lo que se conoce como el principio FIFO (First In, First Out).

Las colas son estructuras de datos lineales caracterizadas porque la inserción de nuevos elementos se realiza por un extremo, mientras que la eliminación de los ya existentes se efectúa por el extremo opuesto. Los componentes se procesan estrictamente en el orden de llegada.

Frente Final
1
2
3

Entra por Final, sale por Frente (FIFO)

3.3.1 Representación

Se puede implementar mediante el uso de arreglos unidimensionales (vectores). Es indispensable definir un tamaño máximo de almacenamiento (MAX) y establecer dos variables de control:

  • Frente: almacena la posición del primer elemento de la cola (el próximo a salir).
  • Final: guarda la posición del último elemento insertado.
3.3.2 Formas de uso

Se utiliza mucho para representar sistemas informáticos, bancos, o la gestión de tareas de un sistema operativo (como la cola de impresión).

Algoritmo de Inserción (Push)

Push_Cola(FINAL, DATO) // Inserta el elemento al final SI FINAL < MAX ENTONCES // Verifica si hay espacio COLA[FINAL] = DATO // Almacena el dato FINAL = FINAL + 1 // Incrementa el puntero FINAL SINO DESPLEGAR MENSAJE: "La cola está llena" FIN SI

Algoritmo de Eliminación (Pop)

Pop_Cola(FRENTE) // Elimina el elemento al frente SI FRENTE < FINAL ENTONCES // Verifica que no esté vacía COLA[FRENTE] = NULO // Elimina el dato FRENTE = FRENTE + 1 // Avanza el puntero FRENTE SINO DESPLEGAR MENSAJE: "La Cola está vacía" FIN SI
3.3.3 Implementación

Si analizamos una secuencia con los días de la semana:

  1. Push: se insertan lunes, martes, miércoles, jueves y viernes.
  2. Pop (FRENTE): el elemento "lunes" será el primero en salir. La posición Frente avanza.
  3. Push (FINAL): se inserta "sábado". Ingresa por el extremo posterior.

¿En qué momento se utiliza una Cola en lugar de una Pila? Por ejemplo, en una cola de impresión: los documentos se forman en una cola y el primero que llegó es el primero en imprimirse. Las colas garantizan que la información se procese en el orden exacto en que llegó.

3.4 Listas enlazadas

En los arreglos la información se almacena de forma contigua (como vagones de un tren). Pero, ¿qué sucede si la memoria está fragmentada y solo hay espacios vacíos separados? Visualiza una búsqueda de tesoro: la primera pista te dice dónde está la segunda. Así funciona una Lista Enlazada. La información está dispersa en la memoria, pero se sabe quién sigue a través de apuntadores.

Una lista simplemente ligada almacena una secuencia lineal de elementos conocidos como nodos. Un nodo consta de:

  1. Un campo que contiene la información.
  2. Un apuntador con la dirección de memoria del siguiente nodo. El último apuntará a NULL.

3.4.1 Representación

Los elementos se almacenan en lugares no contiguos (dispersos).

Diferencias con los arreglos:

  • El acceso aleatorio en un arreglo es inmediato; en la lista hay que recorrer todos los nodos desde el inicio.
  • Las listas requieren memoria extra (para los apuntadores).
  • En las listas es más rápido eliminar o insertar elementos en medio, solo se reacomodan los enlaces.
3.4.2 Formas de uso

Además de la lista simplemente enlazada (un solo sentido), existe la lista doblemente enlazada. Tiene dos apuntadores *izq (predecesor) y *der (sucesor), permitiendo recorrer la lista de inicio a fin y viceversa.

3.4.3 Implementación

Un claro ejemplo de lista doblemente enlazada es la aplicación de Spotify, donde puedes saltar a la canción anterior o siguiente rápidamente.

El tipo struct permite establecer esto en código:

typedef struct ListaIdentificar {
    Elemento *inicio;
    Elemento *final;
    int tamano;
} Lista;

edit_noteCierre: Consolidación y conclusión

Cuadro comparativo formalizando las ventajas y desventajas:

Característica Arreglos (arrays) Lista enlazada
Espacio en memoria Contiguo (uno al lado del otro) Disperso (no está unido)
Tamaño Estático (no cambia durante la ejecución) Dinámico (crece o decrece durante la ejecución)
Acceso a la información Inmediato por índice (A[3]) Lento (hay que recorrer desde el inicio)

Se llega a la conclusión de que, como las listas enlazadas son dinámicas, pueden incrementarse o decrementarse según las necesidades sin desperdiciar memoria.
